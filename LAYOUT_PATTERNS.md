## 12. まとめ：レイアウトの鉄則

### 余白の基本ルール
```
4px  → 最小単位
8px  → 近接要素間（ボタン同士、アイコンとテキスト）
12px → 関連要素間（フォームのラベルとフィールド）
16px → セクション内の要素間
24px → セクション間、カード内のパディング
32px → 大きなセクション間
```

### 視覚的階層
```
最上位       → タイトルバー、ヘッダー（Elevation 4-8）
第2階層      → ナビゲーション、サイドバー（Elevation 2-4）
コンテンツ層  → カード、パネル（Elevation 1-2）
背景層       → ページ背景（Elevation 0）
```

### レスポンシブの考え方
```
モバイル     → 単一カラム、ハンバーガーメニュー
タブレット   → 2カラム、コンパクトナビゲーション
デスクトップ → 3カラム可能、展開ナビゲーション
```
